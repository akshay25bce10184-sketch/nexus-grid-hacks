# Project Overview

**Nexus Grid Hacks** is a modern hackathon registration website designed to provide participants with an engaging and user-friendly experience. The website presents all essential hackathon information including event details, schedule, prize pool, sponsors, FAQs, and registration through a clean, responsive, and interactive interface.

The project focuses on delivering a professional frontend experience using modern web technologies while ensuring responsiveness, accessibility, smooth navigation, and an attractive UI/UX design.
